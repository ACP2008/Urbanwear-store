## ⚠️ Important Limitations

This project currently functions as a **front-end demonstration**, not a complete production-ready e-commerce platform.

- Product, cart, and order data are stored in the current browser.
- Data is not automatically shared between customers or devices.
- Demo orders are not sent to the store owner.
- No real payment is processed.
- The checkout form does not connect to a shipping provider.
- Customer authentication is not production-ready.
- The demo admin login uses hardcoded credentials.
- The newsletter form does not submit data to an email marketing service.

**Do not use the current demo authentication or local order storage for a real online store.**

For production use, implement a secure backend, database, proper authentication, order notifications, and a payment gateway where required.

---

## 🔒 Security Notice

The current admin login is intended only for demonstration purposes.

Before accepting real customer information or orders:

- Replace hardcoded admin credentials with secure authentication.
- Store customer and order data in a secure backend.
- Validate data on the server.
- Protect administrative routes and APIs.
- Integrate a trusted payment provider if accepting online payments.
- Publish appropriate privacy, shipping, cancellation, and return policies.

Never store payment card details or sensitive customer information in browser LocalStorage.
